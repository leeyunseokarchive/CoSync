# 릴스 3 — 「공동창업자 레드플래그 🚩」 (그린/레드플래그 밈)

- **포맷**: 트렌드 차용(그린/레드플래그 밈) + 니치 트위스트. "완전 내 얘기" 공감 스킷. 반전은 마지막 그린플래그.
- **길이**: 약 18초 (짧고 빠르게, 컷 1.5~2초)
- **CTA**: 브랜드 인지 + 댓글 미끼(🚩 개수)
- **음악**: 트렌디한 힙/로파이 비트. 플래그 넘어갈 때 스냅 효과음. 무음 완주 자막 필수.

## 바이럴 설계 노트

- **트렌드 차용**: 인스타/틱톡 "그린플래그 vs 레드플래그" 밈 포맷 → 창업 버전으로 비틀기.
- **"that is so true" 공감**: 창업팀이라면 다 겪은 대사 → 저장·공유.
- **반전**: 레드플래그 쭉 나오다 유일한 그린플래그 = "시작 전에 다 정하는 사람" → CoSync.
- **댓글 미끼**: "당신 코파운더는 🚩 몇 개?" → 댓글 폭발, 도달 확대.

## 촬영 메모

- 대사는 후반 한국어 더빙 + 자막. AI 영상엔 음성 없음(입만 움직임).
- 컷 1.5~2초로 빠르게. 각 플래그마다 화면 상단 🚩/✅ 대형 자막.

## 샷 리스트

### S1 — 훅 (0-3초)
- **화면**: 화자 정면 or 강한 키네틱 타이포. 미니멀 배경.
- **자막**: `공동창업자 레드플래그 🚩` → `이거 있으면 도망쳐요`
- **나레이션**: "공동창업자 레드플래그, 이거 있으면 도망치세요."
- **AI 프롬프트**:
```
미니멀한 현대 공간에서 자신감 있는 젊은 한국 창업자가 카메라를 정면으로 보며 경고하듯 말하는 모습(입 움직임 있음), 살짝 장난기 있는 표정. 트렌디한 색감, 미디엄 클로즈업, 후반 자막 넣을 여백, 9:16 세로. 화면 안에 글자 없음. 실제 음성·대사는 후반 한국어 나레이션으로 삽입 — 생성 영상엔 소리 없음.
```

### S2 — 레드플래그 3연타 (3-11초)
- **화면**: 상황 재연 컷 3개, 각 ~2초. 상단에 🚩 대형 자막.
  - 🚩 컷1: 손 휘저으며 "지분? 나중에 정하지~"
  - 🚩 컷2: 어깨 툭 치며 "우린 친하니까 괜찮아"
  - 🚩 컷3: 귀찮은 표정 "그런 얘기 굳이 해야 돼?"
- **자막(대사)**: `"지분? 나중에 정하지~"` / `"우린 친하니까 괜찮아"` / `"그런 얘기 굳이 해야 돼?"`
- **나레이션**: "지분은 나중에. 우린 친하니까. 그런 얘길 굳이. …전부 3개월 뒤 싸움 예약입니다."
- **AI 프롬프트**:
```
20대 후반 한국인 공동창업자가 사무실에서 세 가지 상황을 연기하는 빠른 컷 몽타주: 손을 휘저으며 대수롭지 않게 말하고, 동료 어깨를 툭 치며 웃고, 귀찮은 표정으로 손사래. 각 컷 캐주얼하고 가벼운 톤, 입이 움직임. 밝은 사무실 조명, 트렌디한 편집, 9:16 세로. 화면 안에 글자 없음. 실제 대사·음성은 후반 한국어 더빙으로 삽입 — 생성 영상엔 소리 없음.
```

### S3 — 그린플래그 반전 (11-15초)
- **화면**: 톤 전환. ✅ 대형 자막. 차분하고 프로페셔널한 인물이 폰으로 CoSync 진단하는 모습 → 갭 리포트 인서트.
- **자막**: `✅ 그린플래그는 딱 하나` → `시작 전에 다 정하는 사람`
- **나레이션**: "그린플래그는 딱 하나. 시작 전에 CoSync로 다 정하고 오는 사람."
- **AI 프롬프트**:
```
차분하고 프로페셔널한 20대 후반 한국인이 카페에서 스마트폰을 보며 만족스럽게 미소 짓는 모습, 신뢰감 있는 분위기. 따뜻하고 깔끔한 조명, 톤이 밝게 전환됨, 9:16 세로. 화면 안에 글자 없음, 대사·음성 없음.
```

### S4 — 엔딩 + 댓글 미끼 (15-18초)
- **화면**: 로고 + 마스코트.
- **자막**: `당신 코파운더는 🚩 몇 개?` → `👇 댓글로`
- **나레이션**: "당신 코파운더는 레드플래그 몇 개예요? 댓글로."
