# 릴스 2 — 반전 「우리 잘 맞을까요?」 (소개팅 반전)

- **포맷**: Bait-and-switch. 설레는 소개팅인 줄 → 공동창업 첫 미팅. 밝고 가벼운 반전.
- **길이**: 약 24초
- **CTA**: 무료 진단 + 댓글 트리거 `진단`
- **음악**: 설레는 어쿠스틱/시티팝(소개팅 톤) → 반전에서 톤 살짝 전환 → 엔딩 산뜻.

## 바이럴 설계 노트

- **어그로 훅**: 초반 완전 소개팅 분위기. "썸 타나?" 궁금해서 봄.
- **이중 의미 대사**: 소개팅으로도, 코파운더 면접으로도 읽힘 → 반전 재미.
- **반전(9초)**: "소개팅이 아닙니다 — 공동창업 첫 미팅입니다."
- 제품 연결: **성격 궁합 말고 창업 궁합**. CoSync 20문항 = 창업 궁합 진단.

## 촬영 메모

- 대사는 후반 한국어 더빙 + 자막. AI 영상엔 음성 없음(입만 움직임).
- 반전은 컷/풀백으로: 로맨틱 투샷 → 명함·노트북·사업계획서 드러남.

---

## 샷 리스트

### S1 — 어그로 훅 (0-4초)
- **화면**: 밝은 카페, 두 사람 마주 앉아 설레는 분위기. 커피 두 잔. 살짝 긴장한 미소.
- **자막(대사)**: A — `"저희… 장기적으로 잘 맞을까요?"`
- **나레이션**: (없음, 대사 더빙 + 설레는 음악)
- **AI 프롬프트**:
```
밝은 카페에서 20대 후반 한국인 두 사람이 마주 앉아 설레는 첫 만남 분위기로 대화, 커피 두 잔, 살짝 긴장한 미소, 입이 움직임. 따뜻한 자연광, 로맨틱한 소개팅 같은 분위기, 영화적 얕은 심도, 9:16 세로. 화면 안에 글자 없음. 실제 대사·음성은 후반 한국어 더빙으로 삽입 — 생성 영상엔 소리 없음.
```

### S2 — 탐색 (4-9초)
- **화면**: 서로 눈 맞추며 조심스레 탐색. 빠른 컷.
- **자막(대사)**:
  - B — `"저는 방향이 제일 중요해요."`
  - A — `"힘들 때 안 도망갈 사람인지가 궁금하고요."`
- **나레이션**: (대사 더빙)
- **AI 프롬프트**:
```
같은 카페, 같은 두 한국인이 서로 눈을 맞추며 조심스럽게 대화하는 모습, 진지하지만 설레는 표정, 입이 움직임. 따뜻한 조명, 로맨틱한 분위기, 클로즈업 빠른 컷, 9:16 세로. 화면 안에 글자 없음. 실제 대사·음성은 후반 한국어 더빙으로 삽입 — 생성 영상엔 소리 없음.
```

### S3 — 반전 (9-14초) ★ 핵심
- **화면**: 카메라 풀백 / 컷. 소개팅 아님 — 테이블에 명함 두 장, 노트북, 사업계획서. 둘이 명함 교환 중.
- **자막**: `*소개팅이 아닙니다` → `공동창업 첫 미팅입니다`
- **나레이션**: "소개팅 같죠? 공동창업 첫 미팅입니다."
- **AI 프롬프트**:
```
카메라가 뒤로 빠지는 풀백 샷. 방금 설레며 대화하던 두 한국인이 사실은 명함을 교환하는 공동창업 첫 미팅. 테이블에 명함 두 장, 노트북, 사업계획서. 카페 조명은 그대로지만 비즈니스 분위기로 전환, 9:16 세로. 화면 안에 글자 없음, 대사·음성 없음.
```

### S4 — 제품 (14-19초)
- **화면**: CoSync 화면 인서트(폰 목업). 20문항 진단 → 갭 리포트(일치/차이/충돌). "창업 궁합" 프레이밍.
- **자막**: `연애는 느낌으로 시작해도` → `창업은 아니거든요` → `성격 궁합 말고, 창업 궁합`
- **나레이션**: "연애는 느낌으로 시작해도, 창업은 아니죠. CoSync가 20문항으로 창업 궁합을 미리 봅니다."
- **AI 프롬프트**:
```
깔끔한 미니멀 SaaS 데모 배경, 부드러운 브랜드 블루 그라데이션, 가운데 스마트폰 목업이 떠 있고 화면 영역은 비어 있음(화면 녹화 얹을 자리). 현대적 테크 감성, 9:16 세로. 화면 안에 글자 없음, 대사·음성 없음.
```

### S5 — 엔딩 + CTA (19-24초)
- **화면**: 로고 + 마스코트. 두 사람 만족스럽게 악수.
- **자막**: `잘 맞는지, 시작 전에 확인하세요` → `댓글 '진단' → 무료 링크`
- **나레이션**: "느낌 말고, 데이터로. 코씽크."
