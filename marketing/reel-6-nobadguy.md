# 릴스 6 — 「나쁜 사람이 없는데 싸웠다」

- **포맷**: 드라마 재연 + 자막 전환. 대화 → 내면 해설 → 결론.
- **길이**: 28초
- **CTA**: 저장 + "우리 팀도 이런 거 있음" 댓글 유도
- **음악**: 초반 긴장감 있는 미니멀 BGM → 자막 구간 무음 또는 페이드아웃.
- **모티브**: 이코노미스트 "미션·비전·역할 기대치가 달랐다" + 루리웹 의사결정 충돌 패턴

## 바이럴 설계 노트

- **악당 없는 구조**: 대표도 잘못 없고, 공동창업자도 잘못 없음. 상황이 문제. 어느 쪽이든 "우리 얘기인데" 반응.
- **"나쁜 사람이 없는데 싸운다면"**: 이 한 줄이 훅. 창업팀 갈등을 가장 정확하게 설명하는 문장.
- **광고 느낌 제거**: CoSync 로고는 마지막 3초에만. 제품 설명 없음.
- **텍스트 구간이 핵심**: 대화 재연보다 "둘 다 한 번도 확인한 적 없었다" 자막 구간이 실제 공감 포인트.

## 촬영 메모

- [0–10초] 사무실 대화 재연. 두 사람, 표정 굳음. 격한 감정 아님 — 당황 + 답답한 톤.
- [10–22초] 흰 배경 or 검은 배경에 자막만. 영화 자막 스타일로 한 줄씩 순차 등장.
- [22–28초] 검은 배경 클로징 + CoSync 로고.
- 대사는 후반 한국어 더빙 + 자막. 자막 없이도 내용 전달 가능하게 편집.

---

## 샷 리스트

### S1 — 오프닝 (0–3초)
- **화면**: 사무실. 두 사람, 서로 마주 보지 않음. 표정 굳음. 정적.
- **자막(전체 화면)**: `창업 13개월째. 처음으로 싸웠다.`
- **AI 프롬프트**:
```
현대적인 스타트업 사무실에서 20대 후반 두 명이 테이블 양쪽에 앉아 서로를 직접 보지 않는 장면. 표정이 굳어 있고 긴장감이 흐름. 조용하고 무거운 분위기. 9:16 세로. 화면 안에 글자 없음.
```

---

### S2 — 대화 재연 (3–10초)
- **화면**: 두 사람 대화. 격하지 않고, 서로 당황하고 답답한 톤.
- **나레이션 + 자막 (교차)**:
  - 대표: *"이번 채용은 내가 결정할게"*
  - 공동창업자: *"잠깐, 그런 얘기 한 적 없잖아"*
  - 대표: *"대표가 채용 결정하는 거 당연한 거 아냐?"*
  - 공동창업자: *"우린 공동창업자잖아"*
- **AI 프롬프트**:
```
스타트업 사무실에서 두 사람이 진지하게 대화하는 장면. 한 명은 설명하듯 말하고, 다른 한 명은 당황한 표정으로 반박. 격한 감정 아님 — 서로 당황하고 답답한 톤. 입이 움직임. 9:16 세로. 화면 안에 글자 없음. 소리 없음.
```

---

### S3 — 내면 해설 ① (10–15초)
- **화면**: 흰 배경. 자막만. 한 줄씩 순차 등장 (영화 자막 스타일).
- **자막**:
  ```
  대표는 생각했다
  "대표가 결정하는 건 당연하다"
  ```
- *(배경음악 페이드아웃 또는 무음)*

---

### S4 — 내면 해설 ② (15–20초)
- **화면**: 흰 배경. 자막 계속.
- **자막**:
  ```
  공동창업자는 생각했다
  "같이 결정하는 게 당연하다"

  둘 다 한 번도 확인한 적 없었다
  ```

---

### S5 — 클로징 (20–25초)
- **화면**: 검은 배경. 흰 글씨.
- **자막 (두 줄, 천천히)**:
  ```
  나쁜 사람이 없는데 싸운다면

  약속이 없는 거다
  ```

---

### S6 — 엔딩 (25–28초)
- **화면**: 검은 배경
- CoSync 로고
- **자막(하단 작게)**: `창업 전에 맞추는 것들`
