# 릴스 3 — 통념 반박 「우린 친하니까」 (바이럴 버전)

- **포맷**: 통념 반박(contrarian) = 댓글·공유 최강. 네거티브 플립 훅.
- **길이**: 약 20초 (짧고 강하게)
- **CTA**: 브랜드 인지 + 댓글 유발(도달 확대)
- **음악**: 톤 있는 로파이/힙 비트, 반박 문장에서 드롭.

## 바이럴 설계 노트

- **네거티브 플립 훅**: "친하니까 괜찮다 → 그게 깨지는 이유" = 스크롤 멈추고 반응(동의/반박).
- 결론 미리 안 말함. 논리 3연타로 몰아붙임.
- **댓글 미끼 엔딩** = 인스타 도달 확대(댓글 가중). 단정 수치 금지, 관찰 어조.

---

## 샷 리스트

### S1 — 네거티브 플립 훅 (0-3초)
- **화면**: 화자 정면 응시 or 강한 키네틱 타이포. 미니멀 배경.
- **자막**: `"우린 친하니까 괜찮아"` → 컷 → `그게 팀 깨지는 1번 이유`
- **나레이션**: "'우린 친하니까 괜찮다'는 팀. 그게 제일 위험합니다."
- **AI 프롬프트**:
```
미니멀한 현대 공간에서 자신감 있는 젊은 한국 창업자가 카메라를 정면으로 보며 말하는 모습(입 움직임 있음). 자연광, 진지하고 약간 도발적인 표정, 미디엄 클로즈업, 후반 자막 넣을 여백, 9:16 세로, 영화적 토킹헤드. 화면 안에 글자 없음. 실제 음성·대사는 후반에 한국어 나레이션으로 삽입 — 생성 영상엔 소리·말소리 없음.
```

### S2 — 논리 3연타 (3-12초)
- **화면**: 빠른 컷 + 강조 자막. b-roll(악수/화이트보드/밤샘) 위 텍스트.
- **자막**: `친할수록 돈·지분 얘기를 미룬다` → `미룬 문제는 안 사라진다` → `잘 될수록 터진다`
- **나레이션**: "친할수록 돈, 지분, 역할 얘기를 미뤄요. 근데 미룬 문제는 안 사라집니다. 오히려 팀이 잘 될 때 터져요. 나눌 게 생기니까."
- **AI 프롬프트**:
```
한국 스타트업 팀의 빠른 영화적 b-roll 몽타주: 악수, 화이트보드에 글 쓰기, 노트북으로 밤샘 작업. 따뜻한 톤에서 차가운 톤으로 전환, 에너지 있는 편집, 후반 자막 넣을 여백, 9:16 세로. 화면 안에 글자 없음, 대사·음성 없음.
```

### S3 — 전환/제품 (12-16초)
- **화면**: CoSync 갭 리포트 초고속 인서트(일치/차이/충돌). 화자 재등장.
- **자막**: `친할 때 미리 정한 팀이 오래 간다` → `CoSync가 20문항으로 대신 물어봄`
- **나레이션**: "그래서 친할 때, 잘 될 때 정해야 합니다. CoSync가 대신 물어봐 줘요."

### S4 — 엔딩 + 댓글 미끼 (16-20초)
- **화면**: 로고 + 마스코트.
- **자막**: `당신 팀은 지분 얘기 해봤나요?` → `👇 댓글로`
- **나레이션**: "당신 팀은 지분 얘기, 해봤어요? 댓글로 알려주세요."
