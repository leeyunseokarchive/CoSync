# 릴스 4 — 「이 말 나오면 메모해」

- **포맷**: 경고형 텍스트 오버레이 + 상황 재연 컷. "이거 들어봤다" 공감형.
- **길이**: 13초 (빠른 컷, 자막 중심)
- **CTA**: 저장 유도 ("나중에 확인하려고 저장함" 유형)
- **음악**: 긴장감 있는 짧은 비트, 각 플래그마다 경고음 효과. 무음 완주 자막 필수.
- **모티브**: SparkLabs "불편한 대화 회피" 실무 케이스 + indiefounders "일단 시작" + eopla 공동창업자 이탈 경험담

## 바이럴 설계 노트

- **저장형 공감**: 창업 경험 있으면 "나 저 말 들었는데" 즉시 반응 → 저장.
- **대표도 공동창업자도 공감**: 이 말이 나쁜 게 아니라, 말한 사람도 들은 사람도 당시엔 당연하게 넘겼다는 게 포인트.
- **짧고 강하게**: 13초 안에 훅 → 3연타 → "나중은 없었다" 한 방. 설명 없음.
- **캡션 확장**: 본문에서 "이 말이 왜 위험한지" 짧게 풀어줌 → 저장 + 공유.

## 촬영 메모

- 대사는 자막으로만 처리. 나레이션 없어도 됨(텍스트 오버레이 포맷).
- 배경: 카페 or 스터디룸. 두 사람이 노트북 펴고 앉은 첫 미팅 세팅.
- 각 플래그 컷 2-3초, 빠른 전환. 자막은 화면 중앙 크게.
- 마지막 "나중은 없었다"는 검은 배경 + 흰 글씨 강조.

---

## 샷 리스트

### S1 — 훅 (0–2초)
- **화면**: 카페, 노트북 두 개, 두 사람 측면 컷 (첫 미팅 분위기)
- **자막(상단 작게)**: `공동창업 첫 미팅`
- **자막(중앙 크게)**: `이 말 나오면 메모해 📝`
- **AI 프롬프트**:
```
카페 창가, 노트북 두 대가 놓인 테이블에서 20대 후반 두 명이 마주 앉은 측면 컷. 처음 만나는 느낌의 가볍고 활기찬 분위기. 커피잔, 메모 노트. 자연광, 따뜻한 색감. 9:16 세로. 화면 안에 글자 없음.
```

---

### S2 — 플래그 ① (2–5초)
- **화면**: 한 명이 손 가볍게 휘저으며 대수롭지 않게 말하는 컷
- **자막(상단)**: `📝 MEMO ①`
- **자막(중앙 크게)**: `"일단 반반으로 하고 나중에 조정하자"`
- **AI 프롬프트**:
```
카페에서 20대 후반 한국인이 손을 가볍게 흔들며 자연스럽게 말하는 모습. 상대방은 고개를 끄덕이는 반응. 가벼운 첫 미팅 느낌. 입이 움직임. 9:16 세로. 화면 안에 글자 없음. 소리 없음.
```

---

### S3 — 플래그 ② (5–8초)
- **화면**: 한 명이 웃으면서 손을 젓는 컷 (별거 아니라는 듯)
- **자막(상단)**: `📝 MEMO ②`
- **자막(중앙 크게)**: `"우리 사이에 계약서가 어딨어"`
- **AI 프롬프트**:
```
카페에서 20대 후반 한국인이 친근하게 웃으면서 손을 젓는 모습. 가볍게 넘기는 듯한 표정. 상대방도 따라 웃음. 자연스럽고 편안한 분위기. 9:16 세로. 화면 안에 글자 없음. 소리 없음.
```

---

### S4 — 플래그 ③ (8–11초)
- **화면**: 두 사람 악수하는 컷
- **자막(상단)**: `📝 MEMO ③`
- **자막(중앙 크게)**: `"일단 시작하고 세부사항은 나중에"`
- **AI 프롬프트**:
```
카페 테이블 위에서 두 사람이 악수하는 클로즈업. 의욕 넘치는 분위기. 따뜻한 조명. 9:16 세로. 화면 안에 글자 없음.
```

---

### S5 — 엔딩 (11–13초)
- **화면**: 검은 배경 + 흰 글씨
- **자막(중앙 크게)**: `나중은 없었다`
- **자막(하단 작게)**: CoSync 로고
