# 릴스 7 — 무료 진단 데모

1~6편이 AI 생성 드라마/밈 포맷이라면 이 편은 **실제 무료 진단 플로우 데모**다.
콜드 도달보다 "이거 3분이면 되네 → 해보자" 전환을 노린다.

- 빌드: `node scripts/reel/make-reel.mjs`
- 대본 수정: `scripts/reel/reel.config.mjs` (자막·타이밍·씬 전부 여기)
- 출력: `docs/reel/cosync-reel.mp4` (1080×1920)

## 촬영 대상

**배포 실사이트의 실제 무료 진단 플로우.** `/mockup/*` 는 쓰지 않는다 (버릴 화면).

```
/onboarding  →  "무료 진단 시작하기"
             →  /onboarding/diagnosis      (시나리오 20문항)
             →  /onboarding/diagnosis/complete
             →  "내 기준 먼저 확인하기"
             →  /gap-report                (내 창업 기준 요약)
```

진단·문항 컷은 **로그인 없이** 촬영한다.

마지막 결과 컷만 로그인 상태의 **팀 통합 리포트**를 쓴다. 혼자 본 "내 기준 요약"은
제품 가치의 절반만 보여주기 때문이다. 팀 전원이 응답한 뒤에야 일치율·히트맵·
충돌 카드가 나오고, 그게 CoSync가 파는 것 자체다.

### 실명 처리

팀 리포트에는 실제 팀원 이름이 뜬다. 공개 영상이므로 **표시되는 이름만
A · B · C 로 치환**한다 (`reel.config.mjs` 의 `ANONYMIZE` / `NAME_MAP`).

- 가명(민서·재윤 등) 대신 A·B·C를 쓰는 이유: 가명은 실존 인물처럼 읽혀
  또 다른 오해를 만든다. A·B·C는 "실제 리포트인데 익명 처리했다"가 한눈에 읽힌다.
- 블러 대신 치환을 쓰는 이유: 블러는 뭔가 숨기는 것처럼 보여 신뢰도를 깎는다.
- **데이터는 전부 실제 값 그대로다.** 일치율 41%, 총 차이 17개,
  고위험 충돌 8개, 히트맵, 각자의 실제 응답 — 아무것도 조작하지 않았다.
- Firestore 실시간 구독이 DOM을 다시 그리므로 MutationObserver로 계속 적용한다.
- 한 글자 이니셜("황")은 부분 치환하면 "상황" 같은 단어까지 망가지므로
  텍스트 노드 전체가 정확히 일치할 때만 바꾼다.

### 계정 정보

코드에 두지 않는다. 빌드 시 환경변수로 넘긴다.

```
CO_ID='...' CO_PW='...' node scripts/reel/make-reel.mjs
```

## 훅 설계

**지어낸 카피를 쓰지 않았다.** 진단 문항 자체가 훅이다.

> "파트너가 마케팅 집행을 위해 500만 원을 사전 합의 없이 단독으로 집행했습니다."

Q11을 훅으로 쓰는 이유는 **일러스트다.** 두 사람이 같은 지출을 정반대로
보고 있는 그림(한쪽 결제완료 ✓ / 한쪽 ?!)이라, '인식 차이'라는 제품 메시지가
자막 없이 한 프레임에 담긴다. 다른 문항 일러스트는 사람이 하나거나 사물 중심이다.

돈 + 구체적 숫자라 의견이 즉시 갈리고, 보기 4개(`역할 범위 내면 문제없다`
→ `금액과 무관하게 공동승인`)가 스펙트럼이라 댓글이 붙는다.

> 앞서 훅으로 썼던 Q2(토요일 밤 IR 덱)는 뺐다. 주말 연락은 워라밸 이슈지
> 동업 리스크가 아니고, 카테고리 가중치도 최하위(역할 & 책임 0.11)다.
> 무엇보다 "내 파트너 답은 뭘까"가 궁금해지지 않는다.

**과장하지 않는다.** "나 몰래 쓴 500만 원" 같은 표현은 쓰지 않았다.
문항은 "사전 합의 없이 단독 집행"이지 은폐가 아니다. 신뢰·합의를 파는
제품이 상황을 과장하면 그 자체로 손해다.

말투도 제품 어미(`~할 것 같아요` / `~하겠어요`)에 맞춘다.
"당신"은 쓰지 않는다 — 번역체로 읽힌다.
질문은 예/아니오가 아니라 열린 형태로 둔다. 보는 사람이 머릿속에서
실제로 답을 만들어봐야 진단으로 넘어온다.

"창업팀 10명 중 9명" 류 수치 훅은 **쓰지 않는다** — 검증된 출처가 없고
README 자체 가이드("검증된 출처 없으면 단정 자막 금지")에 걸린다.

## 왜 이 세 문항인가

진단이 초기부터 엑싯까지 훑는다는 걸 **자막으로 주장하지 않고 화면으로 보여준다.**

| 컷 | 문항 | 단계 | 카테고리 (가중치) |
|----|------|------|------------------|
| 1 | Q11 500만 원 단독 집행 | 시드 · 자금 운용 | 조달 & 운용 (0.17) |
| 2 | Q6 지분 20% 파트너 이탈 | 전 구간 | 이탈 & 회수 (0.11) |
| 3 | Q20 VC 시리즈 A 제안 | 성장기 | **지분 & 보상 (0.28)** |

컷 3은 가중치 최고 카테고리다. 무료 기본 12문항은 앞 4개 카테고리만 다루고,
`지분 & 보상` `의사결정 & 실행` 은 추가 진단(Q13~Q20)에 있다.

진단 전체가 실제로 단계순으로 깔려 있다:

```
Q03 개발 일정 지연        솔루션 검증 / MVP
Q01 베타 출시 후 CS 부재   PMF 탐색 진입
Q02 IR 덱, 투자자 미팅     프리시드~시드 조달
Q10 런웨이 6개월          시드 소진
Q13 온보딩 전환율 개선     PMF 탐색
Q19 출시 18개월 첫 영업이익 PMF 확인
Q20 VC 시리즈 A 제안       시리즈 A
Q07 이상적인 결말?         엑싯 (IPO / M&A / 독립)
```

## CTA 설계

**CTA는 "무료 진단" 하나.** 사전신청은 넣지 않았다.
아직 가치를 못 느낀 시청자에게 이메일부터 요구하면 전환이 죽는다.

퍼널이 이미 그렇게 설계돼 있다:
진단(무료) → 갭 리포트(무료) → 합의 세션 진입 시 벽 → 사전신청 팝업.
릴스는 첫 칸까지만 밀어주면 되고, 사전신청은 제품 안에서 자연히 만난다.

랜딩에 노출 중인 **"현재 41팀 진단 완료"** 는 실측치라 필요하면 자막에 쓸 수 있다.

## 자막 스타일

두꺼운 검은 테두리(YouTube 자동자막 룩)를 버리고,
**하단 스크림 + 굵은 흰 글씨 + 키워드 인디고 하이라이트**로 간다.
앱 화면이 밝고 깔끔해서 검은 테두리가 화면을 지저분하게 만들었다.

## 나레이션

- 음성: **Typecast `고운`** (한국어 여성) — `tc_68785db8ba9cd7503f27d921`
- 파일: `docs/reel/narration/*.wav`
- 재생성이 필요하면 bbanana MCP `generate_audio` (provider: `typecast`)

ElevenLabs 대신 Typecast를 쓰는 이유: ElevenLabs(v2·v3 모두)가 한국어 의문문에서
말끝을 올리지 않아 어색하게 들렸다. `[curious]` `[questioning]` 태그와
stability 조정으로도 개선이 크지 않았다. Typecast는 한국 서비스라 한국어 억양이 낫다.

| 구간 | 나레이션 | 길이 |
|------|----------|------|
| 훅 | 공동창업자가 오백만 원을, 나랑 상의 없이 썼습니다. 어디까지 괜찮다고 보세요? | 6.15s |
| 이탈 | 이 년 같이 한 파트너가 나간다고 합니다. 지분 이십 퍼센트, 정해둔 기준은 없고요. | 6.65s |
| 성장기 | 이런 갈림길은 초기부터 엑싯까지 계속 옵니다. 지금 안 하면, 그때 가서 처음 얘기하게 됩니다. | 7.00s |
| 결과 | 코싱크 무료 진단은 팀의 인식 일치율을 숫자로 보여줍니다. 저희 팀은 사십일 퍼센트였어요. 같은 질문에 셋 다 답이 달랐습니다. | 9.80s |
| CTA | 삼 분이면 끝나요. 프로필 링크에서 확인해보세요. | 4.05s |

**숫자는 한글로 풀어 쓴다.** `500만` `20%` `41%` 를 그대로 넣으면 TTS가 엉뚱하게 읽는다.

**나레이션 길이가 컷 길이를 정한다.** 자막 타이밍에 말을 우겨넣으면 급하게 들린다.
각 씬은 나레이션 + 0.5초 여유로 잡았다 (총 35.2초).
