# 릴스 2 — 문제→해결 데모 「이 카톡」 (바이럴 버전)

- **포맷**: 최고 전환 포맷(문제→해결 데모) + 구체적 실무 훅. 저장·전환·댓글 유발.
- **길이**: 약 24초 (데모 구간 최장)
- **CTA**: 무료 진단 + 댓글 트리거 `진단`
- **음악**: 미니멀 로파이, 데모에서 살짝 업. 무음 완주 자막 필수.

## 바이럴 설계 노트

- **훅은 시각 먼저**: 실제 카톡 알림 화면 = 스크롤 멈춤. 막연한 "팀 갈등" ❌, 구체 순간 ⭕.
- **저장 미끼**: "이거 나중에 우리 팀 때 씀" 심리 자극.
- 데모가 가장 길다 = 제품이 실제로 뭘 하는지 = 전환 핵심.

---

## 샷 리스트

### S1 — 시각 훅 (0-3초)
- **화면**: 폰 채팅 앱 클로즈업. 알림 하나 뜸. 엄지 머뭇.
- **자막(메시지)**: `근데 우리… 지분 얘기 언제 하지?` + 상단 훅 `이 카톡 뜨면 절반은 이미 늦었어요`
- **나레이션**: (알림음 + 정적)
- **AI 프롬프트**:
```
스마트폰 화면 극단적 클로즈업. 팀 채팅 앱에 새 메시지 알림이 뜸(말풍선 안 한국어 텍스트). 엄지손가락이 화면 위에서 머뭇거림. 긴장된 조용한 순간, 얕은 심도, 9:16 세로, 사실적. 말풍선 속 한국어 외 다른 글자 없음, 대사·음성 없음.
```

### S2 — 현재 고통 (3-9초)
- **화면**: 사무실. 어색한 정적, 눈 피함, 말 돌림. 빠른 컷 3개.
- **자막**: `아무도 먼저 못 꺼냄` → `"나중에 하자"` → `그 나중은 안 옴`
- **나레이션**: "지분, 역할, 이탈 조건. 미루다 결국 곪습니다."
- **AI 프롬프트**:
```
현대적 사무실의 소규모 한국 스타트업 팀, 어색한 메시지 직후. 모두 눈 안 마주치고 노트북에 집중하는 척. 불편한 침묵, 은근한 긴장, 차분한 중립 조명, 다큐멘터리풍 빠른 컷, 9:16 세로. 화면 안에 글자 없음, 대사·음성 없음.
```

### S3 — 제품 데모 (9-19초) ★ 최장
- **화면**: CoSync 실제 화면 녹화 4비트(폰 목업, 탭 강조):
  1. 각자 폰으로 **20문항 진단**
  2. **갭 리포트** 일치(초록)/차이(노랑)/충돌(빨강)
  3. **합의 세션** 제안 + 전원 동의 투표
  4. **합의서 PDF** v1.0
- **자막**: `20문항 진단` → `갭 한눈에` → `제안·투표로 타결` → `합의서로 남김`
- **나레이션**: "CoSync는 대신 물어봐요. 갭을 숫자로 보여주고, 합의해서 문서로 남깁니다."
- **AI 프롬프트**:
```
깔끔한 미니멀 SaaS 제품 데모 배경, 부드러운 브랜드 블루 그라데이션. 가운데 스마트폰 목업, 화면 영역은 비어 있음(화면 녹화 얹을 자리). 은은히 떠 있는 움직임, 현대적 테크 감성, 9:16 세로. 화면 안에 글자 없음, 대사·음성 없음.
```

### S4 — 엔딩 + 댓글 트리거 (19-24초)
- **화면**: 로고 + 마스코트. 그 팀 이제 편히 웃으며 문서 봄.
- **자막**: `말 못 꺼낸 그 얘기, 앱이 대신` → `댓글 '진단' → 무료 링크` → `저장 📌`
- **나레이션**: "곪기 전에, CoSync."
