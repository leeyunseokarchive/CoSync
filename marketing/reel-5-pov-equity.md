# 릴스 5 — 「POV: 공동창업자가 내 지분 기대치를 모른다」

- **포맷**: POV 텍스트 오버레이 + 내면 자막 교차. 설명 없이 상황으로만 전달.
- **길이**: 22초
- **CTA**: 저장 + "나도 이랬다" 댓글 유도
- **음악**: 감성 로파이 or 미니멀 피아노. 극적 전환 없이 잔잔하게 끝까지.
- **모티브**: SparkLabs 캡테이블 교착 실무 사례 + eopla 공동창업자 이탈 경험담 ("2년 무임금 후 계약 거부")

## 바이럴 설계 노트

- **양쪽 다 공감**: 대표 시점도, 공동창업자 시점도 동시에 보여줌. 어느 쪽이든 "내 얘기"가 됨.
- **소리 없이 전달**: 텍스트만으로 상황 완성. 지하철에서 무음 시청해도 100% 전달.
- **"나중에 확인" 저장형**: POV 포맷 자체가 저장률 높음. "나도 이런 상황인데" 반응.
- **제품 언급 없음**: CoSync 로고만 마지막에. 콘텐츠 자체가 문제를 설명함.

## 촬영 메모

- 나레이션 없음. 자막 + 화면으로만 전달.
- 화면 분할 없이 자막 교차로 처리 가능 (편집 단순, 틱톡 네이티브 스타일).
- [0–14초] 카페 배경. [14–19초] 노트북 화면(메일) 클로즈업. [19–22초] 검은 배경.
- 두 사람이 웃고 있는데 자막이 무거운 대조가 포인트.

---

## 샷 리스트

### S1 — 훅 (0–3초)
- **화면**: 카페 창가. 노트북 두 대. 두 사람 마주 앉은 모습. (POV 느낌)
- **자막(전체 화면)**: `POV: 공동창업자가 내 지분 기대치를 모른다`
- **AI 프롬프트**:
```
카페 창가, 두 사람이 노트북 펴고 마주 앉은 장면. 편안한 분위기, 대화 중인 듯. POV 카메라 시점 느낌. 자연광. 9:16 세로. 화면 안에 글자 없음.
```

---

### S2 — 대표 내면 (3–8초)
- **화면**: 한 명(대표)이 노트북 보며 뭔가 계산하는 표정. 겉으론 평온.
- **자막(나 = 대표)**:
  ```
  (나)
  아이디어 내가 냈고
  지금까지 제일 많이 일했으니까
  60%는 맞지 않나
  ```
- **AI 프롬프트**:
```
카페에서 20대 후반 한국인이 노트북 화면을 보며 생각에 잠긴 표정. 겉으론 평온하지만 뭔가 계산하는 느낌. 상대방은 흐릿하게 반대편에 위치. 9:16 세로. 화면 안에 글자 없음.
```

---

### S3 — 공동창업자 내면 (8–13초)
- **화면**: 다른 한 명(공동창업자)이 노트북 보며 마찬가지로 생각 중. 겉으론 웃음.
- **자막(상대방)**:
  ```
  (상대방)
  기술 없으면 아무것도 없는데
  50%는 받아야지
  ```
- **AI 프롬프트**:
```
카페에서 20대 후반 한국인이 노트북 보며 살짝 웃고 있지만 내면엔 다른 생각이 있는 듯한 표정. 자연스럽고 가벼운 분위기. 9:16 세로. 화면 안에 글자 없음.
```

---

### S4 — 아무도 꺼내지 않음 (13–17초)
- **화면**: 두 사람이 웃으면서 대화 중 (음소거 처리, 자막만 보임)
- **자막(중앙)**:
  ```
  그리고 아무도
  먼저 꺼내지 않았다
  ```
- **AI 프롬프트**:
```
카페에서 두 명이 웃으면서 활기차게 대화하는 장면. 밝고 편안한 분위기. 창업 미팅 같은 느낌. 음소거로 사용할 예정. 9:16 세로. 화면 안에 글자 없음.
```

---

### S5 — 9개월 뒤 (17–20초)
- **화면**: 노트북 화면 클로즈업, 메일 알림
- **자막**:
  ```
  9개월 뒤
  투자사에서 캡테이블 보내달라는
  메일이 왔다
  ```
- **AI 프롬프트**:
```
노트북 화면 클로즈업, 이메일 받은 편지함이 열려 있는 장면. 긴장감 있는 분위기. 사무적인 조명. 9:16 세로. 화면 안에 글자 없음.
```

---

### S6 — 엔딩 (20–22초)
- **화면**: 검은 배경
- **자막(크게)**: `지분 얘기, 미루면 결정이 된다`
