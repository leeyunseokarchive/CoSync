# CoSync 릴스 마케팅 — 3편 기획

초기 창업팀 대상 AI 영상 릴스 3편. 톤 믹스(드라마 / 정보 / 유머)로 A/B 테스트.

| 항목 | 값 |
|------|-----|
| 플랫폼 | 인스타그램 릴스 (릴스형 전반 재활용 가능) |
| 비율 | 9:16 세로 (1080×1920) |
| 길이 | 20~30초 |
| 언어 | 한국어 (나레이션·자막) |
| 자막 | 항상 켬 (무음 시청 대응). 하단 안전영역 확보 |
| AI 프롬프트 | **한글**. Veo / Sora / Kling 등 text-to-video 생성기용. 영문 프롬프트 쓰면 영상 속 텍스트·음성이 영어로 나와서 한글로 작성. 각 프롬프트에 "화면 안 글자 없음, 대사·음성 없음" 명시 → 자막·나레이션은 후반 삽입 |
| 브랜드 | 로고·마스코트(`../logo.png`, `../mascot.png`) 엔딩 3초 노출 |

## 3편 개요

각 편은 리서치로 검증된 서로 다른 고성과 포맷 사용.

모든 편 **바이럴 버전**: 첫 1-3초 시각 훅·오픈 루프, 결론 미리 안 말함, 요점 2개, 댓글·저장 유발 CTA.

| # | 포맷 | 제목 | 핵심 훅 | 길이 | CTA |
|---|-----|------|---------|------|-----|
| 1 | 반전 드라마 (bait-and-switch) | 알고보니 공동창업자 | 연인 싸움 어그로 → "이 둘은 연인이 아닙니다" | 24초 | 무료 진단 + 댓글 `진단` |
| 2 | 반전 (소개팅 → 코파운더) | 우리 잘 맞을까요? | 설레는 소개팅 → "공동창업 첫 미팅입니다" | 24초 | 무료 진단 + 댓글 `진단` |
| 3 | 트렌드 밈 (그린/레드플래그) | 공동창업자 레드플래그 🚩 | "이거 있으면 도망쳐요" | 18초 | 브랜드 인지 + 댓글 🚩 개수 |

### 댓글 트리거 (DM 자동화)
- 트리거 단어 `진단` → 무료 진단 링크 DM 발송. 릴스 1·2 공용. (ManyChat 등 인스타 DM 자동화 연동)
- "link in bio"보다 댓글 자동화가 도달·전환 유리 (인스타 알고리즘 댓글 가중).

### 포맷 리서치 근거 (2025~2026)
- 시각 훅 first 1-3초 > 텍스트 훅. 무음 시청 대응 자막 필수.
- 최고 전환 = 문제→해결 데모 (문제 5-10초 / 고통 10-15초 / 데모 20-30초 / CTA 5초).
- 댓글·공유 최강 = 통념 반박("대부분 X라 생각하지만…"). 질문형 훅 49% + 충격형 32% = 성공 훅 81%.
- 막연한 문제 금지. 구체적 실무 순간·실제 고객 언어 사용.
- 출처: Markana Media(B2B 릴스 포맷), Sovran(Hook-Body-CTA), OpusClip(1.9M 클립 훅 분석).

## 제품 팩트 (영상에 쓸 근거)

- 20문항 시나리오 진단 (역할/의사결정/보상/지분/이탈 조건 등 6개 카테고리)
- 갭 리포트: 팀원 응답 비교 → **일치 / 차이 / 충돌** 시각화
- 합의 세션: 갭 항목 제안 → 전원 동의 투표 → 항목 타결
- 합의서: 버전 관리(v1.0, v2.0…) + PDF 내보내기
- Free = 진단·갭 리포트까지. Premium = 합의 세션·합의서 전체

> ⚠️ 통계 수치("65%" 등)는 검증된 출처 없으면 단정 자막 금지. "많은 팀이" 같은 표현으로 완화하거나 실제 출처 확보 후 인용.
