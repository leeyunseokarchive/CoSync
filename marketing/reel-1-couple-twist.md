# 릴스 1 — 반전 드라마 「알고보니 공동창업자」 (바이럴 버전)

- **포맷**: Bait-and-switch(어그로 → 반전). 연인 싸움인 줄 → 공동창업자. 강한 패턴 인터럽트.
- **길이**: 약 24초
- **CTA**: 무료 진단 + 댓글 트리거 `진단`
- **음악**: 감정적 발라드/피아노(연인 싸움 톤) → 반전에서 뚝 끊고 긴장 → 엔딩 태그라인 임팩트.

## 바이럴 설계 노트

- **어그로 훅**: 초반 완전 연애 싸움처럼. 시청자 "뭐야 이거" 스크롤 멈춤.
- **이중 의미 대사**: 연인 싸움으로도, 공동창업 갈등으로도 읽힘 → 반전 순간 소름.
- **반전(9초쯤)**: "이 둘은 연인이 아닙니다 — 공동창업자입니다". 여기서 저장·공유·댓글 터짐.
- 태그라인 "창업은 신뢰가 아니라 실전이다. 코씽크"가 전체를 한 줄로 묶음.

## 촬영 메모

- 대사는 **후반 한국어 더빙 + 자막**. AI 생성 영상엔 음성 없음(입만 움직임). 오디오/립싱크 어긋남 방지.
- 반전은 **카메라 풀백**으로: 얼굴 클로즈업(연인처럼) → 확 빠지며 사무실·화이트보드·지분 차트 드러남.

---

## 샷 리스트

### S1 — 어그로 훅 (0-4초)
- **화면**: 얼굴 클로즈업 투샷. 여자 울 것 같은 표정으로 쏘아붙임. 완전 연애 싸움 분위기.
- **자막(대사)**: 여자 — `"왜 맨날 말이 달라져?"`
- **나레이션**: (없음, 대사 더빙 + 감정 음악)
- **AI 프롬프트**:
```
20대 후반 한국인 남녀가 얼굴 클로즈업 투샷으로 감정적으로 다투는 모습. 여자는 울 것 같은 표정으로 쏘아붙이고 입이 움직임. 따뜻하지만 무거운 실내 조명, 연인 싸움처럼 보이는 감정적 분위기, 영화적 얕은 심도, 9:16 세로. 화면 안에 글자 없음. 실제 대사·음성은 후반 한국어 더빙으로 삽입 — 생성 영상엔 소리 없음.
```

### S2 — 격화 (4-9초)
- **화면**: 남자 리액션, 상처받은 표정. 빠른 컷으로 감정 고조.
- **자막(대사)**:
  - 남자 — `"너 나에 대한 신뢰가 단 하나도 없구나?"`
  - 여자 — `"신뢰? 처음에 약속한 거 지킨 적 있어?"`
- **나레이션**: (대사 더빙)
- **AI 프롬프트**:
```
같은 20대 후반 한국인 남자가 상처받은 표정으로 반박하며 입이 움직임, 이어서 여자가 팔을 내저으며 격하게 대꾸. 감정 고조된 다툼, 무거운 실내 조명, 영화적 클로즈업 빠른 컷, 9:16 세로. 화면 안에 글자 없음. 실제 대사·음성은 후반 한국어 더빙으로 삽입 — 생성 영상엔 소리 없음.
```

### S3 — 반전 (9-14초) ★ 핵심
- **화면**: 카메라 확 풀백. 여기 연인 아님 — 사무실. 화이트보드에 사업계획·지분 파이차트, 책상에 노트북 두 대, 명함 두 장. 두 사람은 책상 양쪽.
- **자막**: `*이 둘은 연인이 아닙니다` → `공동창업자입니다`
- **나레이션**: "연인 싸움 같죠? 공동창업자입니다."
- **AI 프롬프트**:
```
카메라가 뒤로 확 빠지는 풀백 샷. 방금 다투던 한국인 남녀가 사실은 스타트업 사무실 책상 양쪽에 서 있음. 벽에는 사업계획과 지분 파이차트가 그려진 화이트보드, 책상에는 노트북 두 대와 명함. 차가운 사무실 조명으로 전환, 긴장된 분위기, 9:16 세로. 화면 안에 글자 없음, 대사·음성 없음.
```

### S4 — 원인 + 제품 (14-19초)
- **화면**: 짧은 회상 — 창업 시작 때 계약서 없이 악수만. → CoSync 갭 리포트 인서트(일치/차이/충돌).
- **자막**: `시작할 때 아무것도 안 정했거든요` → `지분·역할·이탈 조건`
- **나레이션**: "시작할 때 지분도, 역할도 안 정했으니까요. CoSync는 그걸 20문항으로 미리 물어봅니다."
- **AI 프롬프트**:
```
회상 톤의 따뜻한 플래시백: 같은 한국인 남녀가 창업 초기에 서류 없이 밝게 악수만 나누는 모습, 뒤이어 깔끔한 미니멀 SaaS 데모 배경에 스마트폰 목업이 떠 있고 화면 영역은 비어 있음(화면 녹화 얹을 자리). 9:16 세로, 영화적. 화면 안에 글자 없음, 대사·음성 없음.
```

### S5 — 태그라인 + CTA (19-24초)
- **화면**: 검은 배경에 흰 텍스트 임팩트 → 로고 + 마스코트.
- **자막**: `창업은 신뢰가 아니라 실전이다` → `코씽크` → `댓글 '진단' → 무료 링크`
- **나레이션**: "창업은 신뢰가 아니라 실전이다. 코씽크."
