# CoSync 소개 영상 (소셜미디어 홍보용) 설계

## 1. 목적 및 형식

- **용도**: 소셜미디어 홍보용 (인스타그램/틱톡/유튜브 쇼츠)
- **길이/비율**: 30초, 세로 9:16, 1080x1920, 30fps
- **톤**: 문제 공감으로 시작 → 실제 화면으로 해결 흐름 보여줌 → 슬로건 아웃트로
- **내레이션**: 없음. 한국어 텍스트 타이포그래피 자막 + 배경음악만으로 구성 (속도감 있는 모션그래픽)

## 2. 파이프라인

```
1. Firebase 에뮬레이터(Firestore + Auth) 로컬 기동
2. scripts/seed.ts 확장: 팀 1개 + 멤버 3~4명 + 20문항 응답(일치/차이/충돌 혼합)
   + 진행 중인 합의 세션 + 확정된 합의서 v1.0까지 풀 시나리오 데이터 생성
   (premium 계정, 프로덕션 Firestore 미접촉 — 실제 유저 데이터 전혀 사용 안 함)
3. npm run dev (에뮬레이터 연결 상태로) 로컬 서버 기동
4. 에뮬레이터 테스트 계정으로 로그인 (실제 자격증명 아님 — 에이전트가 직접 진행 가능)
5. 브라우저로 6개 핵심 화면 스크린샷 캡처
6. 별도 Remotion 프로젝트에서 스크린샷 + 타이포 자막 + BGM + 전환 애니메이션 합성
7. mp4로 렌더
```

## 3. 스토리보드 (6컷, 30초)

| 컷 | 시간 | 화면 | 자막 카피 |
|---|---|---|---|
| 1. 훅 | 0-4s | 블랙 배경, 타이포only | "팀 만들 땐 신났는데... 지분은? 역할은? 그만두면?" |
| 2 | 4-9s | 온보딩 진단 (`/onboarding/diagnosis`) | "막연한 약속 대신, 20개 질문으로 먼저 확인하세요" |
| 3 | 9-14s | 갭 리포트 (`/gap-report`) | "누가 어디서 다르게 생각하는지 한눈에" |
| 4 | 14-20s | 합의 세션 (`/consensus`) | "차이 나는 부분만, 팀원 전원 합의로 좁혀갑니다" |
| 5 | 20-25s | 합의서 문서 (`/agreement/document`) | "합의된 내용은 문서로, 버전까지 관리" |
| 6. 아웃트로 | 25-30s | 로고 + 슬로건 | "CoSync — 창업은 신뢰가 아니라 실전입니다." |

## 4. 기술 스택 / 산출물

- Remotion 프로젝트 위치: `~/Desktop/Projects/CoSync-intro-video/` (CoSync 레포와 분리된 신규 폴더)
- 스크린샷: 실제 라이브 화면, 심플한 브라우저 목업 프레임 씌워서 삽입
- 타이포: 굵은 산세리프 계열(한글 가독성 우선), 전환은 슬라이드+줌 위주
- 브랜드 에셋: CoSync 레포의 `logo.png`, `mascot.png`을 아웃트로에 사용
- BGM: 로열티프리 후보 2~3개를 먼저 제시 → 사용자가 고르면 그때 다운로드 승인 받고 진행
- 최종 산출물: mp4, `CoSync-intro-video/out/` 저장

## 5. 범위 제외 (Out of Scope)

- 실제 결제/구독 연동 화면은 다루지 않음 (README 기준 현재 임시 팝업 상태)
- 다국어(영문) 버전은 이번 스펙에 포함 안 함
- 음성 내레이션(TTS)은 이번 스펙에 포함 안 함
